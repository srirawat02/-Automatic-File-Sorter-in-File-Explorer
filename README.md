# -Automatic-File-Sorter-in-File-Explorer

## Python File Organizer

A simple Python automation script that organizes files into folders based on their file type.

##  Features
- Automatically creates folders
- Sorts `.csv`, `.png`, and `.txt` files
- Uses Python built-in modules like:
  - `os`
  - `shutil`
  - `pathlib`

##  How It Works
The script scans a directory and moves files into:
- `csv files`
- `image files`
- `text files`


##  Example
Before:
```


doc/
file1.csv
image.png
notes.txt

```

After:
```

doc/
csv files/
image files/
text files/

```
